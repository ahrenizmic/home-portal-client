# home-portal-client

Веб-клиент Home Portal — показывает домашние дела из зашифрованных данных.
Данные лежат в [home-portal-data](https://github.com/ahrenizmic/home-portal-data).

## Как открыть

1. Открой https://ahrenizmic.github.io/home-portal-client/.
2. Введи пароль.
3. Клиент расшифрует данные и покажет дела.

Работает с любого устройства (телефон, планшет, компьютер) — данные и код
раздаются через GitHub Pages.

## Как это работает

1. Пароль → ключ (PBKDF2, соль из `keyparams.json`).
2. Клиент качает `manifest`, расшифровывает, читает `publishId`.
3. Если `publishId` не менялся с прошлого раза — берёт `data` из локального
   кэша (localStorage), не качая из сети. Иначе — качает свежий `data` и
   обновляет кэш.
4. Расшифровывает `data`, показывает задачи.

Формат файлов данных описан в
[home-portal-data](https://github.com/ahrenizmic/home-portal-data).

## Что уже умеет

- Экран задач: группы «Просрочено», «На сегодня», «В ближайшие 2 недели».
- Человеческие даты, сортировка по сроку.
- Сворачиваемые подгруппы по датам в блоке будущего.
- Кэш данных: не перекачивает `data`, если ничего не менялось.

## Известные ограничения

Портал в развитии. Пока НЕ реализовано:

- **События и календарь** — показываются только задачи из проектов.
- **Задачи без срока** (`due`) и запланированные (`scheduled`) — не показываются.
- **Рендеринг Markdown** — текст задач показывается как есть.
- **Вики-ссылки** `[[...]]` — отображаются сырыми, не кликабельны.
- **Офлайн / установка как приложение (PWA)** — ещё нет.
- **Создание задач на устройстве** — только просмотр.

## Безопасность

Пароль вводится локально в браузере, никуда не отправляется. Расшифровка
целиком на устройстве. Кэш в localStorage хранит данные в зашифрованном виде.
